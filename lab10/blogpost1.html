What Is It?

Payment method identifiers(PMIs) are strings that uniquely identify a payment method or payment handler used to complete a transaction, most foramlly defined by the W3C for web payments APIs.
These are used to track payments, orders, and transfers across multiple systems.
There are so many different types of payment identifiers as well that contribute to the overall system that we know as online shopping.
All of these things make up one of the most used services in modern society.

--------------------------------------------------------------------------------------------------------------------------

One of these types of Identifiers are order ids.
This type of identifier is mandatory and needed as part of the first part of a transaction.
Depending on the type of operation the value is provided as the order.id filed in request and response bodies or as an order ID query.
Order IDs are very importnat and are very necessary for things like this to work.

--------------------------------------------------------------------------------------------------------------------------

Order reference is important as well.
In some situations the order ids that you use can't be used in some gateways or don't meet the gateways requirements.
In that case you'd create a brand new and unique order id that fits that gateways requirements.
You could also provide the system with an optional value that contains the identifier that you use in your own personal system.
